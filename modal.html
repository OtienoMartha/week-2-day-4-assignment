About HTML

HTML (HyperText Markup Language) is the structure of every web page. It describes what content is on the page — headings, paragraphs, images, links — using tags. Without HTML, there is no page to style or make interactive.

About CSS

CSS (Cascading Style Sheets) controls how the page looks — colours, spacing, typography, and layout. It separates presentation from structure, letting you restyle the same HTML in completely different ways.

About JavaScript

JavaScript makes pages interactive. It responds to clicks, validates forms, updates content on the fly, and much more. Every modern web application is powered by JavaScript running in your browser.
